# LDOE statewide school finance data: what exists, what was downloaded

Researched 2026-11-19. Everything below was either opened and checked (marked "verified") or is stated from LDOE page listings / zip file listings (marked "listed"). Raw files and a manifest (`manifest.csv`, 487 files, ~1.0 GB, no file over 200 MB) are in `/Users/andrewdunn/dev/schoolbudgets/data/raw/ldoe/<dataset>/`.

Source pages (LDOE moved from louisianabelieves.com to doe.louisiana.gov; the old URL redirects):
- Financial data: https://doe.louisiana.gov/data-and-reports/financial-data
- Enrollment: https://doe.louisiana.gov/data-and-reports/enrollment-data
- Workforce (salaries): https://doe.louisiana.gov/data-and-reports/workforce-attributes
- MFP: https://doe.louisiana.gov/school-system-leaders/school-system-finances/minimum-foundation-program

All file URLs are `https://doe.louisiana.gov/docs/default-source/<folder>/<file>`; full URLs are in the manifest.

## 2. Quirks and format changes (verified unless noted)

- **File label vs fiscal year.** `Year` in AFR files is the school-year start (2018 = FY2018-19). The zip `2014-afr-web.zip` is FY2014-15 and `2024-afr-web-reports.zip` is FY2024-25 (the page labels it "2024 -2025 AFR Web"). The AFSR zips use the same start-year convention in their contents.
- **Three eras of AFR packaging.**
  - FY2006-07 to FY2010-11: comma-delimited .txt zips, plus Access .mdb (2000/2003 format).
  - FY2011-12 to FY2013-14: **Access .accdb only** (193 to ~200 MB uncompressed each). I did not extract the 2011-12 or 2013-14 files. The FY2012-13 file opens with the pure-python `access-parser` package and has the expected tables (AFR 1-7, a group-code table, a keypunch-code table, and a district/site code list of 154 rows including RSD-FirstLine charters). `mdbtools` (not installed) would also work.
  - FY2014-15 onward: .txt (to FY2015-16) then .xlsx (FY2016-17 to FY2021-22; the 2020-21 to 2023-24 expenditure files are .xlsb and need `pip install pyxlsb`). Each zip also carries an .accdb.
- **Header and column changes.**
  - 2006-07 and 2007-08: columns Year, LEA, District, KeyPchCd, Description, Object, Function, Group, ... no site column.
  - 2008-09 to 2010-11 and 2016-17: Grouping, LEA/SiteCode, District/Site Name (one combined column holds LEA and site names).
  - 2015-16 to 2019-20: LEA, District/LEA Name, SiteCode, SiteName, plus an `Extracted` timestamp.
  - 2022-23 onward: renamed to `LEA_Code`, `SiteCd`, `Total_Funds` etc. (underscores).
  - **2014-15 .txt has no header row at all.**
  - **FY2024-25 expenditure file has lost the `Object` column** (and the Restricted/Unrestricted/Capital Outlay columns), and the Function code sits under a column mislabeled `Source`. Salary vs benefit has to be inferred from `Description`/`KeyPchCd` for that year. Revenue columns also differ.
- **KeyPchCd** (the line-item key) is the stable join key across years: it is `15420` in 2006-07 and `0015420` later, so zero-pad it. Description text changes case/wording across years ("a. Kindergarten Teachers" vs older "A. KINDERGARTEN TEACHERS", "Teachers" with different numbering prefixes).
- **Non-expenditure rows are mixed into the expenditure table**: "133/134 balances at beginning/end of year" (about $11.7B each in 2018-19), transfers out and charter pass-throughs (function 5xxx, including "Local Revenue Transfers - Charter Schools" about $2.2B in 2018-19), debt principal and interest, capital outlay. Summing TotalFunds without filtering gives $56B for 2018-19, far more than actual spending. Early years also include **statewide and subtotal rows** (LEA codes 999001, 999002, 999003; "State Totals", "STATE SUMMARY") that double-count if summed.
- **Double counting across LEAs.** MFP dollars flow through the city/parish district to charters ("Local Revenue Transfers - Charter Schools"), so a naive sum across all LEAs counts some money in both the sponsor and the charter.
- **LEA coding and Orleans.** Orleans history: RSD schools appear with an `RSD-` prefix in FY2015-16 (e.g. "RSD- Democracy Prep Louisiana Charter School"), as separate charter LEAs (W codes) by FY2017-18 (e.g. WBE Lusher, 395 Algiers Charter Schools Association), and Orleans Parish (036) holds only the remaining directly run schools. In the per-pupil and MFP files, Orleans is merged under R36 from FY2021-22 (per-pupil) so Orleans is not comparable to earlier years without rolling charters up yourself. Charter LEA codes (3xx, Wxx, 3Cx) change as schools are renamed or merge (e.g. "Warren Easton Charter Foundation, Inc.", "Pierre A. Capdau Charter School" appear only from 2020).
- The FY2022-23 AFSR zip filename is misspelled (`...annual-financial-and-statstical-report.zip`); the URL is as posted.
- **Per-pupil file structure changes**: header row moves (row 5, 6 or 10 depending on year); amounts are rounded to the nearest dollar; percents are fractions (0.44). `Reporting Subcategory` is populated only for Total/Federal/State-Local in the later years.
- **Classroom teacher salary files** are city/parish only, exclude sabbaticals, and the sheets are named differently each year (e.g. "...Averages by School District" vs "...Average by School District"; 2013-14 "all LEAs"). The "headcount" and "full-time equivalent" files stop after FY2010-11; later years only report a single teacher headcount and FTE per LEA.
- **No LDOE file I found gives administrator counts by LEA for every year.** The usable sources are AFSR Table F (October FTE by staff category, xlsx for 2019-20, PDFs for later years that I listed but did not parse; PDF or xlsx for earlier years was not audited) and AFSR Items 6/16 (headcount by race and gender, xlsx 2019-20 to 2023-24).
- **Year gaps.** AFR: none from FY2006-07 to FY2024-25 (but 2011-14 only in Access). Per-pupil: starts FY2016-17, none for FY2024-25. Fiscal-data summary tables end FY2017-18. 70% requirement ends FY2021-22. Enrollment: complete Oct/Feb series Oct 2006 to Feb 2026 (Oct 2025 and Feb 2026 are hosted in the `fiscal-data` folder, not `data-management`).
- **Dataset not found:** the Annual Financial Report Users Guide (referenced on the page, not downloaded), per-school ESSA report-card PPE (the site-level per-pupil file is that data, in different layout).

## 3. Recommendation

**Backbone: AFR Report 2 (expenditures), `afr-data/`.** It is the only source that is (a) every LEA including each charter, (b) available for all of FY2006-07 to FY2024-25, and (c) detailed enough to separate teachers (Object 112 and the "Teachers" lines within Function 1100-series), school administration (Function 2400, principals and assistant principals as their own lines), central/general administration (Function 2300), transportation (2700), plant operations (2600), food service (3100), benefits and retirement, and instruction share, with an LEA-level join key. Teacher-vs-administrator comparisons should be dollar-based from this file (salary dollars, `Description` lines for principals, assistant principals, supervisors, and the 2300 function).

Supplement with:
1. **AFSR Table F and Items 6/16** for FTE/headcount of teachers vs school administrators vs LEA administrators (FY2019-20 onward in xlsx; Table F in 2019-20 breaks out each Type 2 charter). Dollars and positions come from different sources and should be labeled that way.
2. **Enrollment multi-stats (site sheet)** for per-pupil denominators, rolled up by LEA. Use the site sheet rather than the LEA sheet because LEA sheets bundle all Type 2 charters into "CHA" and Orleans into R36 in recent years.
3. **School Finder per-pupil file** as a cross-check and for site-level views. Its five-bucket instruction/administration shares are LDOE's own published numbers and can be cited directly, but the buckets are coarse and Orleans is merged from FY2021-22.
4. **Teacher salary file** for average teacher pay by LEA (not for charters).
5. **MFP budget letters and charter per-pupil** to show state money flowing to each LEA, and the 70% instructional requirement PDFs only as a published official benchmark.

Hard parts to plan for: extracting FY2011-12 to FY2013-14 from Access, handling the FY2024-25 schema (no Object column), filtering out balance/transfer/total rows, and rolling charters into their authorizer where "per parish" comparisons are wanted. Year-over-year change analysis is cleanest within the xlsx era (FY2016-17 to FY2023-24, one schema with minor renames); the FY2006-07 to FY2007-08 data is district-only so it is not comparable to later charter-inclusive totals.
